Events dashboard → day-cycle & kinetic-novel reads

You want to trade the noisy live stream for breathing room: advance the world one cycle at a time with a Proceed button, then read a per-character narrative of what happened to each adventurer that cycle - a kinetic-novel recap instead of terse one-liners.

This hangs together, but it reopens two decisions that Phase 10 deliberately locked. Below is the honest tension, then four forks I need you to settle before I write specs + plans. Each has my recommendation and a one-click answer.

What this overturns - and why that's OK now

  • "Autonomy is the default; intervention is the exception." A Proceed gate makes the player pace tempo. Reframed narrowly, this is fine: the world still resolves each cycle autonomously - the player controls tempo, not outcomes. That nuance needs to land in the spec.
  • "Feed = deterministic templates; LLM for set-pieces only" (rejected per-event LLM for cost / latency / replay-determinism). A cycle boundary generates a bounded batch (one narrative per character per cycle), not a per-event stream - so richer LLM prose becomes feasible again, as long as narrative stays a presentation layer over the deterministic event log (the log remains the replayable source of truth).

How comparable games handle this

Grounding each fork in genre precedent. Short version: your instinct tracks the reading-first management-sim lineage (Football Manager, Persona, Wildermyth) more than the real-time colony-sim lineage (RimWorld, Crusader Kings) - which is exactly right for "breathing room."

# What similar games do Where our lean sits
1 Two camps. Colony/character sims lean real-time-with-pause - RimWorld's AI "Storyteller" (Cassandra/Phoebe/Randy) paces events while you pause to act; Crusader Kings and Norland do the same. But sims built to be read - Football Manager (click Continue to advance; the Inbox is where players spend the most time) and Persona (structured time slots) - use click-to-advance. Deliberate divergence
Fully turn-based moves you from the RimWorld norm toward the FM / Persona reading-first tradition - the camp whose whole point is absorbing a digest at your own pace. That's a considered choice, not the default for this subgenre.
2 Persona is the canonical model. Morning / afternoon / evening slots are widely praised for creating opportunity-cost tension and a rhythm that "mirrors real-life cycles," enhancing immersion. Stardew, Rune Factory, Sunless Sea use similar time-of-day beats. Squarely conventional
Morning/afternoon/night is a proven, well-loved structure - and it gives the kinetic novel natural chapter breaks. Low-risk.
3 Wildermyth is the benchmark for per-character procedural stories: storybook/comic panels generated from each character's traits + hooks, written with "just enough words." Crucially it's hand-authored modular fragments + character data - no AI/LLM. De-risks the fallback
The most acclaimed example of exactly what you want uses rich templates, proving the fallback path can carry the feel. Hybrid keeps that proven floor and adds LLM reach on top - so a missing key degrades to "Wildermyth-style," not "broken."
4 Football Manager's Inbox - a digest hub - is the screen players live in, with granular data screens still reachable beneath it. RimWorld keeps a live event log plus alerts as the always-on record. Standard pattern
Digest-primary with the raw log preserved as drill-down is the established FM shape - readers up top, auditors underneath.

Sources: Wildermyth (gamermatters, cjleo.com design blog), RimWorld / CK3 / Norland pacing (PC Gamer, TV Tropes Real-Time-with-Pause), Persona 5 time slots (Megami Tensei Wiki, Persona Fans), Football Manager Inbox & Continue (Sports Interactive manual, Dot Esports).
