Q11

How does the LLM integration actually work?

Final question
Dependency: Q10 → Q11 — LLM is now generating game-time event text; how does the architecture work? Q10 locked in LLM inline for all social events — not just the day-summary narrator. That means we need to decide: how are character voices encoded (the agent.md idea), how are group scenes composed, how do we gate calls to control cost, and how does the existing day-summary narrator (already wired in LLMNarrator.ts) relate to the new inline layer? This is the final architectural question that makes everything else buildable.
My recommendation — character context cards + batched inline calls + day-summary as editorial layer

Three interlocking pieces:

Piece 1 — Character context cards (the agent.md idea)
Each adventurer has a compact context card (~200 tokens): name, voice descriptor (terse / warm / sardonic), personality axes snapshot, 2–3 defining relationship notes, current mood tag. Card is regenerated when personality or key relationships shift substantially. Included verbatim in every prompt involving that character. Group scenes include all N cards.
Piece 2 — Batched inline calls (cost gate)
Social events are queued in a buffer (max 4–6 events) and sent as a single batched prompt: "Generate a 1–2 sentence event line for each of these encounters." One API call per batch instead of per event. At fast-forward speed, events are queued silently; the batch fires when the player slows to 1× or pauses. At 1× speed, flush after each event or after 30s — whichever comes first.
Piece 3 — Day-summary as editorial layer
The existing LLMNarrator.ts stays. It reads the raw event log (including inline-generated lines) and writes the day-summary as an omniscient narrator who notices patterns — "Bran's been reaching out more since the quest." Two layers: inline = scene text; day-summary = thematic reflection. They don't share a prompt — the summary reads finished events, not the inline context.
Example — group scene prompt shape (SOLIDARITY × DRINKING, 3 characters)
Characters: [Bran — terse, stubborn, haunted] [Mira — warm, pragmatic] [Kira — sardonic, loyal]
Activity: DRINKING · Outcome: SOLIDARITY · Time: 21:00
Relationship context: Bran+Mira: growing trust · Bran+Kira: tense · Mira+Kira: old friends

Write 1–2 sentences of scene text for this moment. Show, don't tell. No outcome labels. Character voices should be distinct.
